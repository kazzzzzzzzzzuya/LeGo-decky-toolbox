# Standing instructions (always active)

For every task: consider it deeply, how to fulfill it above expectations, and what result will make the user really happy without follow-ups or rework. Make no mistakes. Save tokens as much as possible without dropping anything important, in the work and in the output.

# Writing and design skills

- Prose (README, release notes, UI text): follow `.claude/skills/unslop-text/SKILL.md` (MIT, Carter Johnson, vibecoded-design-tells). Run `python3 .claude/skills/unslop-text/scripts/unslop_text_scan.py README.md` before committing prose.
- Visual work (README pictures, previews, layout): follow taste-skill, https://github.com/Leonxlnx/taste-skill (MIT). Show the real thing, no captions under images, no invented figures.
