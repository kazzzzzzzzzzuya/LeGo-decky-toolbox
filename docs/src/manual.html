1Before you start

Legion Go Toolbox is a Decky Loader plugin. It puts the hardware settings Lenovo's Windows app (Legion Space) offers, plus a few extras, into the Quick Access menu of SteamOS. Everything is arranged in six tabs.

Three promises

  • Nothing changes until you switch it on. A fresh install leaves power, fan, lights, buttons and battery exactly as they were. The one exception is the controller type Steam sees, which defaults to a Steam Deck controller so Steam offers gyro (see chapter 9).
  • Every change is checked. After writing a setting the plugin reads it back. If the hardware did not accept it you see a Problem line with the reason instead of a switch that looks on but does nothing.
  • Settings stay applied. They are applied again at start-up, after sleep, when a controller reconnects, and when something else (Steam, another tool, the firmware) changes them back - also while the menu is closed.

What you need

2Installing, updating and removing

Install

  1. Install Decky Loader if you do not have it yet.
  2. Copy legion-go-toolbox.zip onto the Legion Go (Downloads is fine).
  3. In Gaming Mode open the Quick Access menu … → Decky (plug icon) → gear icon → General → turn on Developer mode.
  4. In the same settings open Developer → Install plugin from ZIP file → choose the zip.
  5. Open Legion Go Toolbox from the Decky list.

Getting started

The first time the plugin opens, Getting started sits at the top of the Overview tab: power, Smooth frame rate, Battery playtime and Frame Suite in five short notes. Got it, close this hides it; the Getting started button under About brings it back.

Update

From version 2.10 the plugin looks for new releases itself. When there is one, Update to … appears at the top of the Home tab: press it and confirm Decky's prompt; Decky checks the download and reloads the plugin. About on the Home tab has Check for updates and Install another version, one list for going back as well. Your settings are kept and carried forward automatically.

Updating from 2.9 or older: those versions delete their settings while Decky updates them. Press Backup → Save on the Home tab first; version 2.10 and later bring the backup back by themselves when they start without settings. Installing a zip by hand still works the same way.

Remove

Uninstall it from Decky's plugin list. Before that, switch off Manage power, Custom fan curve and Swap menu buttons if you want the firmware and SteamOS defaults back straight away - the plugin hands these back to the firmware when they are switched off. Your settings stay in ~/homebrew/settings/Legion Go Toolbox/, so a reinstall picks them up; delete that folder to remove them too. Lights, remapping and the charge mode are stored in the hardware and stay as last set.

Reading the screens

  • "… is not available" - the device or SteamOS cannot do this. The text underneath names the reason, and where there is a way to get it, says how.
  • Problem (orange) - the last change did not take effect; the text is what the hardware or system reported.
  • Now - what the hardware is actually doing at this moment, read from the device, not what was requested.

Changes are saved as you make them; there is no Save button.

4Home and battery

Overview

Five rows - Power, Fan, Lights, Buttons, Gyro - each show a one-line summary, for example Custom · 12 W · auto · 60 fps. If a module has a problem, its row shows that instead. Select a row to open its tab.

This game

Below the overview, a row with the running game's name opens and closes a summary of everything the plugin applies to that game: its power profile (with Auto TDP's target, the current watts and the watts it remembered), the Smooth frame rate with frame generation and screen rate, the fan setting in use, and the controller type Steam sees. Select a line to change it in its tab. Closed, the row shows the two most important lines.

Battery

Shows the charge level, whether it is charging, the watts flowing out of (or into) the battery and the time left at that rate, for example 88% · Discharging · 21.4 W · about 1 h 50 min left. This is where you see what Auto TDP saves.

Limit charge to 80 %

Turns on the battery's Long Life mode: charging stops at about 80 %. Worth it if the Legion Go spends a lot of time on the charger. The setting is stored in the firmware and survives reboots; turn it off before a long trip to get a full charge.

Firmware access (acpi_call)

Shown only while the acpi_call kernel module is missing. Install acpi_call builds it on the device and loads it; the custom fan curve and full speed work right after.

QuestionAnswer
What it needsInternet, about 4 GB of free space on the internal drive during the build (freed afterwards), several minutes. The row shows the current step.
What it changesNothing on SteamOS's system partition. The compiler and kernel headers are installed in a throw-away overlay that is deleted afterwards (the technique Legion Center uses); only the finished module is kept, in the plugin's data folder, and loaded when the plugin starts.
After a SteamOS updateA new kernel needs a new build. The section comes back with SteamOS was updated; install once more.
If it failsThe reason is shown; nothing is left behind. Most often: no internet, or SteamOS is not up to date (update, restart, try again).
The installer's steps are tested, but it has not been run on a Legion Go yet. A module that is already installed (Legion Center, Bazzite) is simply used.

Backup

Back up settings writes every setting and profile of the plugin - power and fan profiles, Smooth caps, lights, buttons, controller types, gyro tuning - to legion-go-toolbox-backup.json in your home folder. Restore from backup (select twice) replaces the current settings with it and applies them. Copy the file to another Legion Go to carry your setup over. The gyro's calibration is not part of it: calibrate once after restoring.

About

Reset hardware settings returns Power, Fan, Lights, Battery and Controls to their defaults (all off, Steam Deck controller, default swap layout). It does not touch the gyro's calibration and tuning - those have their own reset in the Gyro tab's advanced options.

5Power

First: open Steam's Performance menu and turn off its TDP limit. If both set the power limit they keep overwriting each other.

Manage power

Hands power control to the plugin. The Now line shows the firmware's actual mode and limit. When you switch Manage power off again, the device is put back into the firmware's Balanced mode.

Power mode

ModeWhat happens
Custom (set the watts)You choose the TDP with a slider, within the range the firmware allows. Needed for Auto TDP and for a custom fan curve.
Quiet / Balanced / PerformanceThe firmware's own modes, the same as Legion Space's. The firmware picks limits and fan curve itself.

Auto TDP for a frame rate

You choose a frame rate; the plugin keeps the power as low as possible while still reaching it. Lower power means a cooler, quieter device and longer battery life.

Setting it up

  1. Power mode: Custom.
  2. Turn on Auto TDP for a frame rate.
  3. Choose a Target frame rate (30, 40, 45, 50, 60, 72, 90, 120 or 144 fps).
  4. Set Maximum TDP - the most it may use - and Minimum TDP - the least it may use.
  5. Set a frame limit at the same number, in the game or in Steam's Performance menu. Without a limit the game simply runs as fast as it can and Auto TDP brings the power down until it reaches the target.

How it decides

SituationWhat Auto TDP does
A game starts that Auto TDP has run beforeStarts at the watts it settled at last time for that game and target - one value on battery, one on the charger - instead of searching from the maximum. The Home tab and the Now line show it as remembered
Frame rate below 90 % of the targetAdds 3 W at once
Frame rate between 90 and 97 % of the targetAdds 1 W
Target held for 6 secondsTries 1 W less
That lower setting cannot hold the targetGoes straight back and leaves that setting alone for 45 seconds - longer each time it fails again, up to 10 minutes. This is what makes it settle instead of bouncing.
Just after a changeIgnores 2.5 seconds of readings while the game adjusts
Menu, loading screen, paused gameKeeps the last setting
No game runningUses your Maximum TDP

Separate settings per game

With this on, the profile you edit belongs to the game that is running, and is used whenever that game runs. Games without their own profile use the default one. Use the default for this game deletes the game's profile.

Smooth frame rate

A steady average is not enough for a smooth picture: every frame has to arrive at the same interval. Uneven frames are what you see as jitter even at 60 fps. Smooth mode sets this up per game.

  1. Start the game and open the Power tab.
  2. Under Smooth frame rate choose a cap, for example 60 fps · screen 60 Hz or 72 fps · screen 144 Hz.
  3. Quit and start the game again once - the cap goes into its launch options. From then on, changing the cap or frame generation applies while the game runs.
  4. In Steam's Performance menu set Framerate limit off for this game, and switch off the game's own frame limiter and V-Sync.
  5. Using lsfg-vk frame generation? Frame generation below the cap reads its multiplier by itself (chapter 10).

What it does

PartHow
Even frame capMangoHud's limiter in early mode, read from a small cap file the plugin keeps up to date (~/.config/lgo-toolbox/smooth/<appid>.conf), so changes apply while the game runs; the Linux counterpart of RTSS's async / front-edge limiter shown in frame-pacing guides. Games without MangoHud's Vulkan layer use DXVK's limiter (DirectX 9-11 games under Proton).
Matching refresh rateWhile the game runs the screen switches to a rate the cap divides evenly, so each frame stays on screen for the same time: 30 and 60 fps at 60 Hz, 36, 72 and 144 fps at 144 Hz. The other caps in the list (45, 50, 90, 100, 120) are offered too, marked screen 144 Hz, uneven: they do not divide 60 or 144 Hz, so the screen runs at its highest rate and some frames stay on screen a little longer. gamescope's own limiter stays off, so limiters never stack. The refresh rate is handed back when the game closes.
Auto TDPAims at the cap and judges the slowest frame of each half second, not only the average. It does not cut power while frames arrive unevenly, and adds power when they keep arriving late. Unevenness the screen causes itself (90 fps at 144 Hz holds every other frame one refresh longer) is not counted, and unevenness that a few more watts do not fix (frame generation, shader stutter) stops adding power for a few minutes instead of climbing to the maximum.

The Now line shows the measured frame rate and the slowest frame; the closer the two, the smoother. Smooth mode puts its settings at the very start of the launch options, so wrapper commands such as lsfg-vk's ~/lsfg or gamemoderun keep working. Your own launch options are kept, and turning Smooth mode off removes exactly what it added. HelixSR, Decky-Framegen and similar plugins keep working; Decky-Framegen and Steam ROM Manager replace the whole launch options when they apply, and the Power tab then offers Add the cap again. For emulators from Steam ROM Manager prefer the emulator's own frame limiter: MangoHud's limiter cannot reach Flatpak apps. Games with Smooth mode lists every game with a cap.

Limits. Stutter from shader compilation or loading comes from the game itself and cannot be removed by a limiter. Smooth mode works in Gaming Mode only.

Battery playtime

Choose how long the running game should last on battery, for example 4 h, or As long as possible. The section first shows how long the battery lasts at the current draw and the longest this game can reach from the current charge at your lowest frame rate. That estimate learns what the game draws at each power limit while you play on battery and gets more exact over time.

With a goal, the plugin works out a power budget - energy left ÷ hours to go - and checks the battery's real draw against it every few seconds. It gives up as little as possible, in this order:

  1. Power limit. Too much drawn: the TDP comes down a watt or a few at a time. Plenty to spare for two minutes: it goes back up.
  2. Frame rate, evenly. When the game cannot keep its Smooth cap on that budget, the cap steps to the next even one the screen divides (60 → 48 → 36 → 30), never below your Lowest frame rate (30 by default). Your own cap stays as you set it; the lower one is only used while the goal needs it.
  3. Frame generation, with Frame Suite. With Frame Suite installed and lsfg-vk set up, the first step down is "half the frames, doubled by lsfg-vk" instead: 60 → 30 × 2 = 60 on screen, for far less power. Frame Suite prepares lsfg-vk for the game (off until needed); lsfg-vk picks that up from the game's next start, and from then on it is switched on and off while you play. If even that is too much, frame generation's own cost goes too.
  4. Your lowest frame rate wins. If the goal is out of reach at that rate, the plugin says so and makes the battery last as long as it can without going lower.
SettingWhat it does
GoalHours on battery from now, or as long as possible. The list marks which goals are within reach of the current charge.
Lowest frame rateFewest frames the game itself makes. Frame generation can double them on screen.
Frame generation for battery timeLets the plugin ask Frame Suite for lsfg-vk. The description says when it is ready, or why not.
Count from now againStarts the goal's hours again without changing it.

The count runs only while the game runs on battery. On the charger everything goes back to your own settings and the count waits; after charging by 10 % or more it starts again. Setting a goal switches Manage power on. The Home tab shows the goal's time to go.

Set a Smooth frame rate first. Without one only the power limit is lowered, and the frame rate falls unevenly instead of stepping to an even cap. Screen brightness counts too: the screen alone draws several watts.
Not verified on a device yet.

CPU boost

Turning boost off keeps the processor at its base clock. It runs cooler and quieter and often costs only a few frames, especially together with a frame limit.

6Fan

Requirement. The Legion Go only accepts a fan curve through a Lenovo firmware call, and Linux can make that call only with the acpi_call kernel module. SteamOS does not include it: use Install acpi_call in the Home tab (chapter 4). If the module is already present - installed with Legion Center's Install Fan Support, or on Bazzite - the curve editor appears by itself. Without it the fan follows the firmware's own curve, which is safe.

Custom fan curve

The firmware keeps control of the fan and of overheating protection; the plugin only changes the curve it follows. The firmware uses a custom curve only in the Custom power mode. If the Power tab has a firmware mode selected, the Fan tab says Not in use right now.

Presets

Fan level per temperature (°C). The firmware's scale goes up to 115.

Pick a preset, or move the ten At … °C sliders yourself (the preset then shows Custom). The small graph shows the curve and, as a dashed line, the current temperature.

Safety limits

  • No point can be set below Lenovo's own minimum for the Legion Go - the Silent row above. Handheld Daemon enforces the same limit.
  • The curve always rises with temperature: raising a point lifts the points after it, lowering a point lowers the ones before it.
  • Saved curves from older versions are raised to this minimum automatically.

Full speed

Runs the fan at maximum, ignoring the curve.

Per game and on charger

Two switches let the fan setting depend on what you are doing:

  • Separate settings per game - a game can have its own setting.
  • Separate settings on charger - one setting on battery, another while plugged in.

With both on there are up to four kinds of setting. The plugin uses the most specific one that exists:

OrderSettingExample
1This game, on the chargerElden Ring plugged in: full speed
2This gameElden Ring on battery: Balanced
3All games, on the chargerAnything else plugged in: Cool
4All gamesAnything else on battery: Silent

It switches by itself when a game starts or closes and within two seconds of plugging in or unplugging.

Making a setting

  1. Get into the situation you want to set up - start the game, and plug in or unplug.
  2. Open the Fan tab. The heading names what you are editing, for example ELDEN RING · on charger. Until you change something it says Using the general setting and which one.
  3. Change the preset, the curve or full speed. From then on that case has its own setting.

Use the general setting here removes the setting you are looking at. Saved fan settings lists every setting with its preset; selecting one removes it.

Why a setting can "turn itself off" - and what the plugin does

The firmware throws away full speed and the custom curve whenever the power mode changes - no matter whether Steam, another tool, Auto TDP or a manual change caused it. The fan then quietly falls back to the stock curve and temperatures climb.

The plugin therefore reads both back from the firmware every 5 seconds, and one second after each of its own power changes, and puts them back when they are gone. When this has happened the Fan tab shows a Kept on line, for example The firmware dropped the fan setting 3 times (last just now); the plugin put it back.

9Gyro

The Legion Go has three motion sensors: one in each detachable controller and one in the tablet. The Gyro tab uses them in two separate ways.

Gyro in Steam games

Any game, through Steam Input. Uses the tablet's sensor, so it works with the controllers attached - like a Steam Deck.

Gyro for emulators

Dolphin, Ryujinx, Eden, Cemu and others. Each controller's own sensor, so detached controllers work like Wii Remotes or Joy-Cons.

Gyro in Steam games

Steam offers gyro settings only for controllers that have a gyro. On its own, InputPlumber presents the Legion Go as an Xbox controller, which has none. The plugin therefore presents it as a Steam Deck controller by default.

TypeResult
Steam Deck controller (default)Steam's full gyro options; A/B/X/Y lettering like Xbox
Xbox controller (no gyro)No gyro in Steam; what InputPlumber does without this plugin
DualSense / DualSense EdgeGyro; PlayStation symbols in Steam's menus and in games with their own PlayStation support

A different type for one game

While a game is running, a second list with the game's name appears. Choose a type there and it is remembered for that game: the plugin switches to it whenever the game starts and back to the all-games type when it closes. Same as all games removes the game's own choice; so does selecting the game under Games with their own type.

Note. Switching type reconnects the virtual controller, so Steam may briefly show a controller notification as a game starts.

Button symbols

Most games show Xbox symbols whatever type you pick, because Steam Input hands every game an Xbox-style controller. Games with their own PlayStation support may switch to PlayStation symbols when Steam sees a DualSense; most of them have a button-prompt option in their own settings. Steam's own menus and the controller-settings screen always show the type you picked. The Steam Deck type keeps A/B/X/Y lettering, which makes it the best all-round choice.

Setting up gyro in a game

  1. Pick the type before starting the game - changing it reconnects the controller once.
  2. In the game press the Steam button → Controller settings → Gyro and set it up like on a Steam Deck (for example As mouse or As joystick, enabled while touching the right stick).
Layouts per controller type. Steam stores controller layouts separately for each controller type. After switching type, a game may start with that type's default layout.

10With frame generation and upscalers

The plugin works alongside lsfg-vk (Lossless Scaling frame generation), Decky-Framegen (OptiScaler), HelixSR, and Frame Suite, which bundles the three. The key is to know which frame rate each part controls.

ToolWhat it doesFrame rate it changes
HelixSRUpscaler: renders at lower resolution and scales upNone - the game simply needs less power for the same frame rate
lsfg-vk 2.0Frame generation as a Vulkan layerShown frames = game frames × multiplier
Decky-FramegenOptiScaler frame generation inside the gameShown frames = game frames × 2
MAKOAdaptive frame generation (in Frame Suite)Holds a frame rate on screen; generates what the game does not make
Frame SuiteMAKO and the three above in one plugin, set up per gameWhichever of them it set up for the game

HelixSR (upscaling only)

  1. Install HelixSR for the game with its plugin as usual.
  2. Use Smooth mode and Auto TDP exactly as described in chapter 5. Both keep HelixSR's launch settings.

Because the game renders fewer pixels, Auto TDP settles at fewer watts for the same frame rate - the main gain.

lsfg-vk 2.0: Smooth mode with frame generation

One limiter does the whole job. MangoHud's limiter usually comes after lsfg-vk (decky-lsfg-vk installs lsfg-vk in your user folder, which Vulkan loads first), so it sees the generated frames too. The plugin therefore sets it to the frame rate on screen - cap × multiplier, 120 for 60 × 2 - and the game itself settles at the cap. Where MangoHud comes first (lsfg-vk installed system-wide), it caps the game's own frames instead; the plugin tells the two apart from where each is installed. Turning Smooth mode off lifts the cap at once, also in a running game.

  1. In decky-lsfg-vk turn it on for the game with the multiplier you want, for example 2×, and leave its Base FPS cap off. The Power tab warns Two frame limiters when it is on.
  2. Power tab → Smooth frame rate: choose the game's cap, for example 60.
  3. Frame generation below it stays on Auto: the plugin reads the game's multiplier from lsfg-vk's own settings (~/.config/lsfg-vk/conf.toml) and shows it, for example Auto · lsfg-vk 2× · 60 → 120 fps. A multiplier changed in decky-lsfg-vk is followed within seconds, even while the game runs.
  4. Steam's Framerate limit off. The plugin sets the screen rate for the final rate, and Auto TDP aims at it (120) instead of the cap.

Prefer a fixed value? Choose Off or 2×-4× instead of Auto. The Power tab says when it differs from lsfg-vk's setting. The plugin only reads lsfg-vk's files and never changes them.

Cap × multiplierOn screenLegion Go screen (60 / 144 Hz)
30 × 260Even at 60 Hz
72 × 2, 48 × 3, 36 × 4144Even at 144 Hz
60 × 2, 45 × 2120, 90Built-in screen runs at 144 Hz (slightly uneven); 120 is even on a 120 Hz monitor or stream
The cap must be reachable. Frame generation only doubles what the game delivers: a 72 cap the game holds at 45 shows about 90, not 144. Choose a cap the game holds steadily - the Now line shows the shown frame rate.

MAKO (adaptive frame generation)

MAKO's adaptive mode holds a frame rate on screen, for example 72, and generates whatever the game does not make, up to a set number of times. The plugin reads that target from Frame Suite, so there is nothing to set:

PartWith MAKO adaptive
Smooth frame ratePuts the screen at a rate the target divides (72 → 144 Hz). Its own cap is not used; the limiter only backs MAKO up at the target.
Auto TDPAims at MAKO's target: the least power that keeps it on screen. MAKO uses its generated frames before watts are added, never more than its most generated frames.
Battery playtimeMoves only the power limit: MAKO already trades real for generated frames as power drops.

MAKO's fixed mode (2×, 3×) counts like any frame generation: the cap times the frames. A fixed Frame generation setting in Smooth mode wins over MAKO. With lsfg-vk on for the same game, lsfg-vk counts (and Frame Suite warns about two frame generators).

Choose the target in Frame Suite: 72 or 144 on the Legion Go's own screen (even), 60 at 60 Hz. With at most 2× generated frames the game itself never makes fewer than half of it.
Not verified on a device yet.

Frame Suite

Frame Suite tells the plugin what it set up for each game, so there is nothing to choose here. Games it gave lsfg-vk are followed like any lsfg-vk game. For games it gave OptiScaler:

  1. Choose the game's cap under Smooth frame rate, for example 60, and leave Frame generation on Auto.
  2. When you turn frame generation on in the game's own settings, also turn on Frame generation is on in the game for that game in Frame Suite. Within seconds, also mid-game, Auto shows Auto · in-game 2× (Frame Suite) · 60 → 120 fps: the cap counts the frames on screen (120), the game makes 60, and Auto TDP aims at 120.
  3. Turn that switch off again when you turn frame generation off in the game.

With lsfg-vk switched on for the same game, lsfg-vk's multiplier counts instead, so frames are never multiplied twice. The plugin only reads Frame Suite's file (~/.config/frame-suite/bridge.json) and never writes to it; Frame Suite adds its launch settings next to the cap instead of replacing it.

Not verified on a device yet.

Decky-Framegen

OptiScaler generates frames inside the game, so the plugin cannot see whether frame generation is switched on. It does see Decky-Framegen's wrapper, or the DLL override of its direct patch, in the game's launch options and says so under Frame generation.

  1. Choose the game's cap under Smooth frame rate, for example 60.
  2. When you turn frame generation on in the game's own settings, set Frame generation to 2×. The cap then counts the frames on screen (120), the game makes 60, and Auto TDP aims at 120.
  3. Set it back to Off when you turn frame generation off in the game; otherwise the game would run uncapped up to 120.
Not verified on a device yet. Using only Decky-Framegen's FSR 4 upscaling with lsfg-vk for frame generation needs none of this: leave Frame generation on Auto.

External screens with variable refresh

On a screen with VRR the cap is held just below its top rate - 116 on 120 Hz, 138 on 144 Hz - so variable refresh stays active, and Auto TDP aims at that number. The Legion Go's own screen has no VRR, so nothing changes there.

11Troubleshooting

SymptomWhat to do
A feature says "not available"The text under it gives the reason. Most often: no acpi_call (fan), not in Gaming Mode (Auto TDP), or InputPlumber not running (buttons, Steam gyro).
TDP keeps jumping backTurn off Steam's own TDP limit (Performance menu) and remove other TDP plugins.
Auto TDP stays "at your maximum"The game cannot reach the target within your Maximum TDP. Raise the maximum or lower the target.
Auto TDP says "waiting for the game to draw frames"No game is in focus, it is paused, or you are in Desktop Mode. Otherwise the line names the reason. While streaming (Steam Remote Play, Punktfunk) gamescope does not report frame times by default; the plugin switches its frame reporting for as long as it measures and puts it back afterwards.
Stream shows another frame rate than the deviceThe stream runs at the client's refresh rate and repeats frames when the game is slower. The game's real frame rate is the one in the Power tab.
Fan full speed or curve switches itself offThe firmware drops them when the power mode changes. The plugin restores them within about 5 seconds; the Fan tab's Kept on line shows when it did.
No fan curve editorThe acpi_call module is missing: Home tab → Install acpi_call (chapter 4).
Stick lights or remapping: "controllers not found"Wake the controllers by pressing a button, then change the setting again.
Menu buttons back to normalInputPlumber restarted; the swap is re-applied within a few seconds.
No gyro option in Steam's controller settingsGyro tab → the type for All games (or for that game) must not be Xbox controller. Restart the game after changing it.
PlayStation symbols in a gameThe game supports PlayStation controllers natively. Use its button-prompt setting, or give that game the Steam Deck type.
Emulator gets no motionCheck the server address and slot; the Gyro tab shows "1 emulator connected" once it works. tools/dsu_monitor.py prints the live data without an emulator.
"Port 26760 is already used"Another motion server is running (EmuDeck can install one). Stop it, or pick another port here and in the emulator.
Smooth mode says a limiter is already setThe game's launch options already cap the frame rate (for example lsfg-vk's frame-generation cap). Use that one, or remove it before choosing Smooth mode. Two limiters cause uneven frames.
Motion driftsLay the controllers down and press Calibrate.
An axis moves the wrong wayGyro → Advanced options → that slot → Tuning → Invert.
